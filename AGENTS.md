# Правила работы

- Работать только в этой папке проекта. Перед изменениями сначала читать текущие файлы, относящиеся к задаче.
- Делать только ту функцию, которую просит пользователь. Не ломать уже работающие функции.
- Использовать только обычные HTML, CSS и JavaScript. Не использовать npm, фреймворки и внешние ресурсы.
- Данные пользователя должны оставаться в браузере. Ничего не отправлять в интернет.
- Использовать понятные подписи. Поля и кнопки должны быть не меньше 44 × 44 px. Обеспечивать работу с клавиатуры и на телефоне.
- Показывать деньги с пробелами между тысячами и знаком тенге: `15 000 ₸`.
- Пустые и неверные числовые значения считать нулём. Никогда не показывать `NaN`.
- Не запускать git и ничего не публиковать без просьбы пользователя.
- После работы перечислять изменённые файлы и объяснять, как проверить результат.
