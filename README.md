# Смета за 5 минут

Веб-приложение для быстрого составления сметы или коммерческого предложения и сохранения документа в PDF.

Для кого:

- Предприниматели — подготовить коммерческое предложение клиенту.
- Офисные сотрудники — составить смету закупки или список расходов для руководителя.

## Файлы приложения

Планируемая структура (файлы приложения пока не созданы):

- `index.html` — структура страницы: поля, список позиций, итог и кнопки.
- `styles.css` — оформление, удобные размеры элементов и адаптация для телефона.
- `script.js` — расчёт сумм, обработка действий пользователя и подготовка сохранения в PDF.

## Как открыть

Когда появится `index.html`, откройте его двойным щелчком. Приложение будет работать в браузере без установки npm и других инструментов.

## Как проверить

После реализации расчёта добавьте две позиции:

1. Количество — 2, цена — 15 000 ₸. Сумма — 30 000 ₸.
2. Количество — 1, цена — 8 000 ₸. Сумма — 8 000 ₸.

Ожидаемый итог: **2 × 15 000 + 1 × 8 000 = 38 000 ₸**.

Сейчас созданы только README.md и AGENTS.md; проверить расчёт можно будет после реализации приложения.
